# 正气打卡

一个适合 iPhone 添加到主屏幕使用的戒色自律打卡 PWA 应用。纯前端、无后端，数据只存在本机浏览器。

## 功能

- **首页**：戒第 X 天、正气值、随坚持天数成长的树（种子 → 发芽 → 小苗 → 小树 → 开花大树）、每日良言
- **每日打卡**：自由决定是否打卡
  - 「今日守住了」：可写心得体会（选填）
  - 「我破戒了」：**必须填写破戒教训**才能提交，连续天数清零重新计算
- **记录**：月历视图，绿色 ✓ 为守住、红色「破」为破戒，点击任意一天可补记 / 修改 / 删除
- **我**：当前连续、历史最长、累计成功、破戒次数统计；破戒教训墙；JSON 数据导出 / 导入

## 在 iPhone 上使用

1. 用 Safari 打开部署后的网址（如 GitHub Pages）
2. 点底部分享按钮 →「添加到主屏幕」
3. 从主屏幕图标启动，全屏运行，体验和原生 App 一致

## 本地预览

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 技术

- 原生 HTML / CSS / JS，零依赖
- localStorage 本地存储，隐私不出设备
- Service Worker 离线缓存
- `manifest.json` + `apple-touch-icon` 支持 iOS 主屏幕全屏运行
